# 统一地产浏览与角色主题设计

## 目标

统一玩家端、银行端和实体落点声明的地产浏览体验：支持中文与拼音搜索、按本局已选角色筛选、清晰显示产权归属，并用角色主题色和抵押状态提升扫描效率。

## 共享组件

- 提取一个可配置的共用地产浏览组件，供“我的地产 / 全局地产”“全地图地产”和“声明实体落点”使用。
- 浏览模式只展示地产信息；落点模式额外接受已选地产名和选择回调，保留既有确认落点流程。
- 搜索、角色筛选、排序、所有者格式、主题色边框和抵押标签都由共享组件处理，不在银行端、玩家端或落点面板重复实现。

## 搜索与筛选

- 保留中文、无声调全拼连续片段、首字母连续片段和中拼混输搜索；忽略大小写与空白。
- 标签只显示当前房间中已选择人物的玩家，不显示未入座角色或银行身份。
- 标签文字只显示角色名，不显示玩家昵称；“全部”使用中性深色，角色标签使用各自主题色填充。
- 标签与关键词取交集；“全部”清除所有者限制。

## 地产卡片

- 已持有地产排在国库地产之前；每组保持服务端提供的原始地产顺序。
- 所有者统一显示为“角色名（玩家昵称）”，其中玩家昵称为灰色；无主地产显示“无主”。
- 已持有地产使用角色主题色的左侧隔离线；国库地产使用黑色左侧隔离线：
  - 宜修：浅蓝 `#6fb6dc`
  - 甄嬛：淡黄 `#e7bd3f`
  - 年世兰：淡紫 `#b487d4`
  - 沈眉庄：淡玫红 `#d96f93`
  - 安陵容：淡绿 `#71b979`
- 抵押地产保留所有者主题色，不降低整卡透明度；右下角添加贴合边框的“已抵押”标签，并继续显示既有抵押价与租金业务数据。
- 在落点模式中，当前选择仍以独立选中轮廓标识，不覆盖产权主题色。

## 数据与兼容性

- 使用现有地产 `ownerId`、玩家 `id`、`name` 与 `characterId`；不新增 API、数据库字段或持久化筛选状态。
- 角色名和主题色由现有角色 ID 映射派生。无有效角色的所有者回退为其昵称和中性边框，避免历史数据导致渲染失败。
- 银行端和玩家端既有的完整价格、租金、冷宫免过路费、购买价和升级费用信息保持不变。

## 验证

- 为筛选模型增加已选角色标签来源、所有者优先排序和主题色元数据的测试。
- 为共享组件增加所有者格式、角色标签文案、国库边框和抵押标签的渲染测试。
- 覆盖浏览和落点两种模式的卡片展示；运行类型检查、ESLint、全量单元测试与生产构建。
