# 伙伴卡审批弹窗设计

## 目标

使“获得伙伴卡”的银行审批弹窗只展示与该事件相关的信息，避免地产、金额和数量的通用占位内容造成误解。

## 界面行为

- `COMPANION_EVENT` 使用独立审批内容，不显示“地产：无”“金额：0 两”或“数量：无”。
- 当申请玩家当前人物为甄嬛时，弹窗显示“自动奖励 500 两”。
- 其他人物的伙伴卡审批不显示奖励金额。
- 所有人物均显示“伙伴卡事件批准后立即生效，不可撤销”。
- 放回伙伴卡及其他审批事件的既有展示保持不变。

## 验证

- 浏览器契约测试覆盖甄嬛的伙伴卡审批：显示自动奖励说明，且不显示通用地产、金额、数量内容。
- 浏览器契约测试覆盖非甄嬛的伙伴卡审批：不显示奖励说明，也不显示通用地产、金额、数量内容。
