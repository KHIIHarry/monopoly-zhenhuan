# 过路费入口审批门控

## 目标

使“支付过路费”快捷入口与“购买 / 建造”一致：只有当前玩家的地产落点已由银行确认且剧情结算完成时才可点击。

## 交互规则

- 快捷入口始终显示。
- 没有已确认且剧情结算完成的地产落点时，入口禁用，不能打开支付面板。
- 落点确认后，入口可点击。
- 打开后的支付面板继续负责其他业务不可支付状态：无主、自有、抵押、地主冷宫中、已结算、金额为零或数据缺失；这些状态的确认支付按钮禁用并显示原因。

## 实现边界

复用既有 `landingConfirmed` 作为入口的启用条件，并继续保留 `busy`、行动权和强制停轮限制。不会改变过路费金额、支付接口、服务端落点校验、资产操作，或沈眉庄剧情罚俸逻辑。

## 验证

扩展过路费端到端用例：无确认落点时快捷入口必须禁用；确认且剧情已结算的落点时入口可用，并仍能提交绑定落点的既有过路费请求。
