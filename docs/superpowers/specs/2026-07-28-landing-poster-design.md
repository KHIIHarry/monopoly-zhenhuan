# 宫廷海报首页设计

## 目标

将首次进入应用时的首页重构为竖版宫廷海报。保留“加入游戏组”按钮现有的 `setScreen('LOGIN')` 行为，不更改登录、房间或游戏流程。

## 素材策略

素材来源为仓库根目录的 `板式2-元素拆分.PNG`。将其裁为独立的本地 Web 静态素材：红色纹理背景、宫殿天空、金色边框、人物组合、花卉与云纹装饰、游戏标题、副标题和加入游戏组按钮。运行时不得把整张设计图或拆分示意图作为页面背景。

## 组件边界

- `PosterBackground`：渲染延展纹理和竖版海报内的宫殿背景。
- `PosterFrame`：渲染金色边框。
- `PosterCharacters`：渲染人物组合。
- `PosterTitle`：渲染标题及副标题。
- `PosterDecorations`：渲染前景花卉与云纹。
- `PosterJoinButton`：渲染可访问的按钮，并接收原有点击回调。

首页只负责组合这些组件及传入登录跳转回调。

## 响应式与层级

外层占满 `100dvh`，处理 `safe-area`，并禁止页面滚动。内层海报固定为竖版比例（约 `2 / 3`），高度使用可用视口和 `clamp()` 限制，宽度由比例自然计算。手机按可用高度整体缩放；iPad 和桌面保持居中的竖版海报，外层纹理背景用 `cover` 延展两侧，不横向拉伸海报。

海报以 Grid 叠层。纹理和宫殿背景在底层，人物居中，标题位于人物下方，花卉在前景，边框覆盖最上层且不接收指针事件。按钮使用最高的可交互层级，人物、标题和按钮均使用 `object-fit: contain` 维持原始比例。定位优先采用比例、Grid、Flex、`clamp()` 和 `aspect-ratio`，不依赖大量固定像素坐标。

## 可访问性与验证

保留按钮名称“加入游戏组”、键盘可聚焦能力和焦点样式。新增首页视觉测试，检查海报主要层存在、无页面溢出、按钮可点击并进入登录界面。通过 Playwright 在 360x800、390x844、768x1024、1024x768、1440x900 进行截图与交互验证，并运行类型检查、lint 和相关端到端测试。

## 非目标

不修改 API、登录流程、房间流程或现有“加入游戏组”的行为；不将整张参考设计图直接作为背景。
