# 房间列表状态徽标设计

## 目标

在房间列表中将圆角状态徽标紧跟在房间名称后，让用户能同时识别自己的加入状态和房间当前阶段。

## 状态映射

- 未加入且未结束：显示“可加入”与阶段徽标。
- 已加入且未结束：显示“已加入”与阶段徽标。
- `LOBBY`：显示“准备中”。
- `PLAYING`：显示“游戏中”。
- `ENDED`、`FINISHED`、`CLOSED`：显示“已结束”，不再显示成员身份徽标。

身份徽标和阶段徽标分别由已有的 `mine` 和 `status` 字段派生，不新增接口或持久化字段。

## 展示与更新

- 每个徽标为小尺寸圆角填充标签，置于房间名右侧。
- “已加入”使用绿色，“可加入”使用蓝色，“准备中”使用金色，“游戏中”使用红色，“已结束”使用中性灰色。
- 窄屏下，房间名和徽标允许换行；人数、时间和进入箭头维持现有布局。
- 列表通过已有的加载、加入后刷新与页面重新进入流程重新计算徽标；不改变既有房间实时订阅边界。

## 验证

- 浏览器测试覆盖未加入准备中、已加入准备中、已加入游戏中、未加入游戏中，以及结束房间的徽标组合。
- 浏览器测试断言徽标使用指定类名和对应填充色，并保留现有房间行的可点击行为。
