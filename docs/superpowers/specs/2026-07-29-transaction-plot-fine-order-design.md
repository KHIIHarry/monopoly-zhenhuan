# 事务板块剧情罚款排序设计

## 目标

将银行端“事务”板块中的剧情罚款模块移动到内容最上方，方便银行在处理其他事务前录入剧情卡罚款。

## 展示规则

- “剧情罚款”标题及其表单成为“事务”内容的第一个模块。
- 原有“轮次控制”“停轮管理”“账务修正”“地产人工修正”“危险操作”和“最近操作日志”依次后移，内部顺序不变。

## 行为与数据

- 不修改罚款玩家、金额、提交按钮、二次确认或沈眉庄减免文案。
- 不修改 `POST /api/rooms/:id/events/plot-fine` 请求、参数或提交后的刷新行为。
- 仅变更 React 渲染顺序，不涉及 API、Socket、数据库或样式变更。

## 验证

- 浏览器测试打开银行端“事务”，断言“剧情罚款”是该内容区域中的第一项标题。
- 既有剧情罚款输入、二次确认和请求路径保持可用。
