# 房间生命周期时间展示设计

## 目标

在用户房间列表和超管后台的房间管理列表中展示每个房间的创建、开始和结束时间。

## 数据契约

- 用户房间列表的房间摘要新增 `createdAt`、`startedAt` 与 `endedAt`。
- 超管房间管理列表的房间摘要新增 `startedAt`，并沿用已有的 `createdAt` 与结算记录中的 `endedAt`。
- `startedAt` 来自房间记录；`endedAt` 来自结算记录。两者在尚未发生时均为 `null`。

## 展示规则

- 两处界面使用同一个前端格式化函数，日期显示为 `xxxx年xx月xx日 星期x 0:00`，采用 `zh-CN` 本地时区。
- 创建时间始终显示格式化日期。
- 开始时间为空时显示“未开始”。
- 结束时间为空时显示“未结束”。
- 时间信息在每个房间条目的现有摘要信息下方显示为一行，以保证房间列表与管理列表的一致性。

## 验证

- API 集成测试断言两个列表接口返回完整的生命周期时间字段。
- 浏览器测试覆盖列表的完整日期格式和“未开始”“未结束”空值文案。
