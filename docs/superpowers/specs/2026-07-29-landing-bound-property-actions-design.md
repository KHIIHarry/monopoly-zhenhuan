# 落点绑定的购买与建造

## 目标

消除玩家在“购买或建造”面板中选择任意地产的入口。购买和建造都只能针对本回合已由银行确认、且剧情已结算的实体落点。

## 范围

- 购买地产：仅当确认落点为无主地产时可提交购买申请。
- 建造升级：仅当确认落点归当前玩家、未抵押且未满级时可提交建造申请。
- 不改变资产操作中的地产选择，也不改变服务端既有的落点校验。

## 界面与数据流

玩家端从当前确认的 `LandingEvent` 取得 `propertyName`，再在快照地产中查找同名地产作为唯一目标。购买或建造面板将“目标地产”呈现为只读信息，不渲染选择控件，也不保留可切换的目标状态。

面板根据当前模式和该落点地产状态决定可提交性：

- 购买模式要求地产无主。
- 建造模式要求地产所有者为当前玩家、未抵押且建筑等级低于五级。
- 没有确认落点、落点状态不符合当前模式或当前地产不存在时，显示原因并禁用提交按钮。

请求路径仍从该唯一目标地产名称构造。服务端继续以已确认的 `LandingEvent.propertyId` 校验购买和建造请求，以保证直接调用 API 也不能选择其他地产。

## 测试

添加玩家端端到端回归覆盖：在确认落点为 A、另有符合通用条件的 B 时，购买与建造面板仅显示 A 的信息，不提供地产选择器，并且提交请求路径仅指向 A。覆盖无主落点购买及自有落点建造两个场景。

## 非目标

- 不改变落点声明、银行确认或资产操作流程。
- 不改变购买、建造金额及技能折扣计算。
