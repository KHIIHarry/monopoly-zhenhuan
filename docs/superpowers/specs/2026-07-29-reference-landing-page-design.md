# 参考风格首页设计

## 目标

将根路径首页改为用户指定参考页的宫廷纸本视觉，并在桌面与移动尺寸保持可用；原有“加入游戏组”点击行为与路由保持不变。

## 设计

首页继续通过 `LandingPoster` 承接 `AppRouterClient` 提供的 `onJoin` 回调。组件改为一个语义化的页面结构：两侧灯笼、宫殿纹样、标题、副标题、骰子装饰、命运文案、加入按钮和右下角印章。加入按钮保留 `data-testid="landing-join-button"`、可访问名称和原来的回调，不引入新的首页状态。

视觉样式放在 `globals.css` 的 `landing-*` 作用域中。桌面端让中央宫廷面板置于深朱色全屏背景中；移动端收紧留白、缩小装饰并仍保证按钮和标题不裁切。动画只用于非交互骰子装饰，并为 `prefers-reduced-motion` 禁用。

## 清理

删除旧的六个首页图层组件及 `public/assets/landing/` 下仅由它们使用的八张插图。`character-standees.png` 仍由其他页面使用，保留。

## 验证

先添加静态结构与样式断言并观察其失败，然后实现至通过。使用 Playwright 在桌面和移动 viewport 验证首页标题、加入按钮可见且点击仍进入登录流程；运行 web 构建以验证类型与 Next.js 编译。
