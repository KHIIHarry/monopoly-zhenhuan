# 账本交易时间与倒序展示设计

## 目标

让玩家端和银行端的账本清楚显示每笔实际余额变动的金额与交易时间，并将最新交易放在列表最上方。

## 范围

- 玩家端的“最近交易”与完整“交易账本”；
- 银行端的“房间账本”；
- 每条账本记录显示金额、说明、交易类型和 `7月31日 14:30` 格式的交易时间；
- 账本按交易时间从新到旧排列；玩家端的“最近交易”取排序后的前三笔。

不新增数据库字段、迁移或新的时间来源。`LedgerEntry.createdAt` 是不可变账本记录已有的权威交易时间。

## 数据流

`PrismaGameService.snapshot` 已按 `LedgerEntry.createdAt desc` 查询可见账本。快照需要原样返回该时间。前端的 `LedgerEntry` 类型接收时间字段，并由单一格式化函数使用本地中文格式化为“月日 时:分”，不显示秒。

前端 `Ledger` 组件直接按接收到的倒序数组渲染，不再反转数组。该组件被玩家的紧凑交易列表、玩家完整账本和银行完整账本共用，因此三处排序与时间展示保持一致。

## 兼容与异常

测试夹具或旧快照没有交易时间时，界面不显示时间文本，不渲染空标签或 `Invalid Date`。真实服务端账本记录始终具备 `createdAt`。

## 验收

- 服务端快照中的账本项包含 `createdAt`；
- 三处账本都显示如“7月31日 14:30”的交易时间；
- 最新账本记录显示在第一行，玩家“最近交易”显示最新三笔；
- 既有不带时间的前端测试夹具仍可正常渲染；
- 涉及的单元测试与类型检查通过。
