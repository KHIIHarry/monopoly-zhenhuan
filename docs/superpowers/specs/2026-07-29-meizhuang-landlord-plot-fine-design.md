# 沈眉庄地主剧情罚款减免设计

## 目标

当沈眉庄向其他玩家支付剧情罚俸或损失时，支持按原始剧情金额录入，并自动减免 200 两。该支付属于地主收款，不进入国有罚款流程。

## 展示规则

- 仅当前付款玩家的人物为沈眉庄时，在“玩家转账”抽屉中显示勾选框。
- 勾选框文案为“剧情罚俸或损失时勾选”。
- 勾选框下展示提示：“金额填写实际罚款金额，系统会自动计算扣减-200，请不要填写减后的金额”。
- 其他人物，以及沈眉庄未勾选该项时，维持原有玩家转账界面和行为。

## 结算规则

- 勾选后，输入框填写剧情卡的原始罚款金额。
- 系统向收款玩家发起的转账金额为原始金额减 200 两。
- 原始金额小于或等于 200 两时，实际付款为 0 两，禁止提交转账。
- 此功能仅适配玩家间转账；现有国有剧情罚款接口及其沈眉庄自动减免逻辑保持不变。

## 验证

- 浏览器回归测试验证沈眉庄打开玩家转账时可见勾选框和提示，填写 500 两并勾选后请求金额为 300 两。
- 验证原始金额为 200 两时，确认转账按钮不可用。
- 验证非沈眉庄付款人不显示该勾选框，且普通转账金额保持原值。
