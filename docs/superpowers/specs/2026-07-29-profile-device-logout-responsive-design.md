# 设备退出按钮响应式设计

## 目标

在个人信息页的已登录设备卡片中，保证“退出设备”在手机宽度下不因剩余横向空间不足而折行。

## 方案

- 宽度大于 560px 时，设备信息与“退出设备”按钮继续横向排列，按钮保持右侧操作位。
- 宽度小于等于 560px 时，设备卡片改为纵向排列；按钮置于设备信息下方、占满卡片可用宽度。
- 为按钮设置 `white-space: nowrap`，使“退出设备”始终在一行显示。
- 不改变设备退出确认弹窗、禁用状态、设备信息或“退出其他所有设备”操作。

## 验收标准

- 在 560px 及以下宽度，“退出设备”显示为单行、全宽按钮，且不遮挡或压缩设备信息。
- 在大于 560px 宽度，现有卡片的横向布局保持不变。
- 样式测试验证窄屏规则包含纵向布局、全宽按钮和不换行约束。
