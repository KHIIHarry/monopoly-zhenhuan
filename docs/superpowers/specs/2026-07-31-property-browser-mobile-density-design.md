# 地产浏览页移动端紧凑布局设计

## 目标

优化共享地产浏览组件在移动端工作台中的宽度、密度和视觉层级，避免搜索框与地产卡片紧贴页面边缘、边框占满内容区域。玩家首页“我的地产”、玩家端“全局地产”和银行端“全地图地产”统一生效。

本次保留 `LandingPropertyCardPicker` 的搜索、筛选、排序、展开、键盘操作和数据结构，只调整 `browse` 模式在 430px 及以下视口的样式。声明地点 `landing` 模式和桌面布局保持不变。

## 现状原因

- 工作台中的标题和多数模块使用 `16px` 左右边距，但 `.browse-property-picker` 直接铺满 `.workbench-scroll` 宽度。
- 浏览模式继续使用桌面的 48px 搜索框、220px 折叠卡高度、22px 标题和较大的卡片内间距。
- 共享组件因此在 375px、390px、430px 设备上显得过宽、过高，卡片主题边框靠近屏幕边缘，单屏有效信息偏少。

## 响应式布局

在 `max-width: 430px` 下，为 `.browse-property-picker` 添加以下专属规则：

- 组件左右各保留 `16px` 页面边距，搜索、筛选、提示、卡片和空状态在同一内容边界内对齐。
- 组件内部间距收紧至约 `8px`；地产网格卡间距约 `10px`。
- 搜索框高度调整为 `40px`，输入字体保持 `16px`，避免 iOS 聚焦缩放；搜索图标同步缩至约 `16px`。
- 筛选按钮保持约 `40px` 触控高度，使用更紧凑的横向内边距和 `11px` 字号；标签文字保持单行，只允许按钮之间换行。
- 展开提示使用更小字号和内边距，保持单行；若极端长文案超出时才允许正常换行。

不使用 `transform: scale()`，所有尺寸逐项调整。

## 地产卡片

- 折叠卡和无结果虚线框统一为 `184px` 高。
- 卡片内边距约为 `12px 10px 12px 14px`，元素间距约 `8px`。
- 宫殿标题调整为 `19px`；辅助标签约 `11px`；核心金额、角色名和建筑等级约 `13px`；玩家昵称约 `10px`。
- 产权标签、冷宫提示和抵押印章按新卡片高度重新缩小、定位，不能遮挡标题或核心数据。
- 卡片主题边框、产权颜色、抵押透明度和所有业务状态保持不变。
- 展开卡片不固定为 `184px`，详情继续按内容自然增加高度；既有价格四宫格、空地、1 至 4 级和大宫殿模块结构不变。

## 作用范围

所有规则均以 `.browse-property-picker` 为前缀，统一作用于：

- 玩家首页“我的地产”；
- 玩家端“全局地产”；
- 银行端“全地图地产”。

声明地点弹层使用 `.landing-action-sheet` 的既有紧凑规则，不受此次修改影响。桌面端继续使用现有卡片宽度、220px 折叠高度和自动多列布局。

## 测试与验收

先新增样式契约测试，再实施 CSS：

- 430px 以下 `.browse-property-picker` 具有 `16px` 左右边距；
- 搜索框为 40px 且输入字体为 16px；
- 筛选按钮保持约 40px 触控高度和单行文字；
- 折叠卡和空状态统一为 184px；
- 卡片标题、核心数据、昵称、抵押章均使用紧凑尺寸；
- 规则不作用于桌面端或声明地点模式。

完成后运行共享组件测试、全量 Vitest、类型检查和 Web 生产构建。按项目要求使用 Docker Compose 运行系统，并通过真实共享组件检查 375px、390px、430px：页面和网格无横向溢出，搜索与卡片左右边界对齐，五角色筛选只在按钮之间换行，折叠卡尺寸一致，展开详情无内容遮挡。
